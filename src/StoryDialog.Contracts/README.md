# StoryDialog.Contracts

Экспорт публичного контракта StoryDialog 0.1.0. Владелец — репозиторий StoryDialog,
исходник — `api/storydialog/v1/dialog.proto`, проект — `clients/dotnet/StoryDialog.Contracts.csproj`.

Меняйте схему у владельца, затем обновляйте `Protos/dialog.proto`. Локальный
контейнерный smoke проверяет совпадение схем. Снимок позволяет собирать бот
без соседнего checkout и неопубликованных NuGet-пакетов.
