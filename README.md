# Занимательные истории голосовых помощников

«Занимательные истории» — игра для голосовых помощников. Помощник просит назвать слова, например имена и прилагательные, вставляет их в историю и читает получившийся текст.

Чтобы начать игру в Алисе, скажите «Давай сыграем в занимательные истории» или откройте навык.
