# Трассировка

Jaeger разворачивается отдельно от сервиса и прокси. OTLP доступен только в общей
Docker-сети, интерфейс и проверка готовности — только на loopback хоста.
Контейнер ограничен 512 МиБ и половиной CPU. В памяти хранятся последние 5000
трасс; старые вытесняются, при перезапуске Jaeger история теряется. На диск
трассы не записываются, размер логов ограничен 30 МБ.

## Включение

Скопировать `jaeger-compose.yml` и каталог `jaeger/` рядом с `rollout.sh`.
Запустить только новый стек:

```bash
docker compose -f jaeger-compose.yml up -d
curl --fail http://127.0.0.1:13133/status
```

После готовности Jaeger задать в `app.env`:

```dotenv
AppConfiguration__Tracing__Enabled=true
AppConfiguration__Tracing__Host=jaeger
AppConfiguration__Tracing__Port=4317
AppConfiguration__Tracing__NetworkEnabled=true
```

Применить окружение через `./rollout.sh <версия>`, даже если образ не менялся.
Новый цвет стартует параллельно, проверяется `/health` и его включение в Traefik;
только после этого старый цвет получает сигнал плавной остановки.
Docker healthcheck удерживает запускающийся контейнер вне Traefik до первого
успешного ответа `/health`. При остановке readiness старого экземпляра может
возвращать 503, пока пользовательские запросы ещё обслуживаются.
Не пересоздавать активный контейнер через `docker compose up` и не перезапускать прокси.

Экспорт выполняется пакетно в фоне с очередью 1024 спана и таймаутом 3 секунды.
При недоступности коллектора телеметрия может теряться; запросы не ждут доставки
спанов в Jaeger. Подробные сетевые источники включаются отдельным флагом и нужны
на время диагностики. HTTP connection setup — отдельная трасса, связанная с
исходящим HTTP-спаном через ссылку, а не обычный дочерний спан.

Интерфейс доступен через SSH-туннель:

```bash
ssh -N -L 16686:127.0.0.1:16686 <ssh-хост>
```

Открыть `http://localhost:16686`, выбрать сервис `FillInTheTextBot.Api`.
Спаны `Dialogflow DetectIntent` и `SetContextInternalAsync` содержат RPC-метод,
агента и код результата; фоновые работы сохраняют связь с исходной трассой.
Тела запросов и ответов, идентификаторы пользователей и секретные пути вебхуков
в трассы не записываются. Включать `Dialogflow.LogQuery` для этого не требуется.

## Проверка и откат

Во время переключения проверять внешний `/health`, ответы сервиса и число
готовых серверов в Traefik. После включения сравнить частоту ошибок, p95/p99,
CPU, память и очередь потоков с интервалом до включения. Проверить поступление
RPC- и сетевых спанов, отсутствие перезапусков/OOM и свободное место на диске.

Если появилась деградация, установить `AppConfiguration__Tracing__Enabled=false`
в `app.env` и снова выполнить `./rollout.sh <версия>`. Это отключает подписки
трассировки, сохраняя сбор метрик. После переключения можно остановить только
Jaeger: `docker compose -f jaeger-compose.yml stop`. Если необходимо немедленно
снять нагрузку коллектора, его можно остановить ещё до переключения сервиса.
